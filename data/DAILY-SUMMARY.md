# บทวิเคราะห์จากผู้ดูแล

1. เปิด `data/daily-summary.txt` บน GitHub แล้วกดรูปดินสอ (ต้องมีสิทธิ์แก้ไข)
2. พิมพ์เฉพาะบทวิเคราะห์ ขึ้นบรรทัดใหม่ได้ตามปกติ ไม่ต้องใส่ JSON วันที่ เวลา หรือชื่อผู้เขียน
3. กด **Commit changes** แล้วรอเว็บเผยแพร่

หน้าเว็บดึงวันที่และเวลาไทยจาก commit ล่าสุดที่แก้ไฟล์นี้โดยอัตโนมัติ ไม่ใช้เวลาที่ผู้เข้าชมเปิดหน้าเว็บ หากบทวิเคราะห์ไม่ใช่ของวันนี้จะมีข้อความกำกับ

หาก GitHub API ใช้งานไม่ได้หรือถึงขีดจำกัด หน้าเว็บยังแสดงบทวิเคราะห์ แต่ระบุว่ายังตรวจสอบเวลาบันทึกไม่ได้ ไม่แสดงวันเวลาที่คาดเดา

เว้นไฟล์ว่างเพื่องดแสดงบทวิเคราะห์ ห้ามใส่ข้อมูลลับเพราะไฟล์เป็นสาธารณะ บทวิเคราะห์ไม่เปลี่ยนระดับเตือนอัตโนมัติ

# บทสรุปรายวันจากผู้ดูแล

แก้ไฟล์ `data/daily-summary.json` ผ่าน GitHub ด้วยบัญชีที่มีสิทธิ์เขียนโครงการ แล้วกด **Commit changes** รอเว็บ deploy สำเร็จจึงจะปรากฏต่อผู้เข้าชมทุกคน

```json
{
  "date": "2026-11-05",
  "time": "08:30",
  "author": "ผู้ดูแล",
  "summary": "ใส่บทสรุปสถานการณ์ที่ตรวจสอบแล้วที่นี่\nใส่คำแนะนำและเวลาของข้อมูลที่ใช้อ้างอิง"
}
```

- `date`: วันที่ของบทสรุป รูปแบบ `YYYY-MM-DD` (ค.ศ.) ตามเวลาไทย เปลี่ยนเป็นวันที่จริงทุกครั้ง
- `author`: ชื่อผู้เขียนหรือหน่วยงาน
- `time`: เวลาที่สรุปตามเวลาไทย รูปแบบ 24 ชั่วโมง `HH:mm` เช่น `08:30` (ต้องระบุเมื่อมีข้อความสรุป)
- `summary`: ข้อความสรุป ใช้ `\n` เพื่อขึ้นบรรทัดใหม่ ไม่รองรับ HTML
- หากต้องการงดแสดงข้อความ ให้ตั้ง `summary` เป็น `""`
- หน้าเว็บระบุเมื่อบทสรุปไม่ใช่ของวันนี้ และไม่เปลี่ยนระดับความเสี่ยงอัตโนมัติตามข้อความนี้
- ห้ามใส่รหัสผ่านหรือข้อมูลลับในไฟล์นี้ เพราะเป็นข้อมูลสาธารณะ

ตัวอย่างเป็นรูปแบบไฟล์เท่านั้น ไม่ใช่การประเมินสถานการณ์จริง
